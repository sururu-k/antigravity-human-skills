# Antigravity Human Skills & Rules (AI臭さ・脚色・ズレ根絶集)

過去の膨大な開発・発表資料作成ログ（フィードバック・苦情・改善指示）を徹底的に分析し、
**AI特有の「安っぽいデザイン」「勝手な脚色・推測」「難解な日本語」「レイアウトのズレ」を根絶**するために策定された、Google Antigravity専用のカスタムSkills & Rules集です。

---

## 🎯 解決するペインポイント（過去ログからの教訓）

1. **AI特有の安っぽいWebカードUI（class="content-card"等）の全廃**
   - 角丸ボックス、不要な影、灰色のキャプションバーなど「いかにもAIが作ったUI」を禁止し、人間が普通に作る正統派のプレゼンデザイン（16:9全面活用、見出し＋実写写真・公式図）を徹底。
2. **勝手な脚色・事実捏造の絶対禁止**
   - ユーザーが指示していない文言（「誰がどの順番で動くか」「新人研修」勝手なチーム名など）の追加を禁止。一次情報・事実のみを記録。
3. **推測ベースの知識ではなく、一次情報・公式リソースを検索・取得**
   - 「aiの推測ベースの知識なんて誰も欲しくねぇ」という教訓に基づき、公式サイト・公式リポジトリの実データをcurl/API等で確認してから記述。
4. **文字サイズ縮小・枠のガタつき・ズレの完全防止**
   - 見出し34px以上、本文20px以上を保証。スライドごとの枠の位置や高さをピクセル単位で完全統一。
5. **難解なAI日本語・不自然なカタカナ構文の排除**
   - 誰にでも直感的に伝わる平易で自然な日本語を使用。

## 🚀 使い方（Antigravityへの導入）

### 1. プロジェクト単位で使用する場合
本リポジトリの `rules/` や `skills/` を対象プロジェクトの `.agents/` ディレクトリにコピーします：
```bash
cp -r skills/ /path/to/your-project/.agents/skills/
cp -r rules/ /path/to/your-project/.agents/rules/
```

### 2. グローバル設定として使用する場合
すべての会話セッションで有効にするには、`~/.gemini/config/` 配下に配置します：
```bash
mkdir -p ~/.gemini/config/rules
cp rules/*.md ~/.gemini/config/rules/
```
