# Rule: Strict Factual Accuracy

1. **推測ではなく一次情報**
   - WebサイトのURL、リポジトリのソースコード、公式ドキュメントを直接取得（curl / fetch / view_file）して確認した事実のみを根拠とする。
   - 「〜と思われます」「一般的には〜」というAI特有の推測でユーザーの報告内容を上書きしない。

2. **ユーザー提供事実の改変禁止**
   - ユーザーが「社員研修」と言ったら「新人研修」に変えない。
   - ユーザーが「カレー作りで価格表をもとに段取りを考えた」と言ったら、勝手に「誰がどの順番で動くか」などの余計なプロセスの脚色を盛り込まない。
