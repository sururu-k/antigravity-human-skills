# No-AI Presentation Skill

## 概要
AIツールが生成しがちな「SaaSのLPのようなカードUI」「小さすぎる文字」「スライドごとの枠ズレ」「AI自作の奇妙な図」を排除し、大学・学会・企業発表で人間が作成する高品質なスライドを出力する。

## 必須デザイン仕様
1. **解像度とキャンバス**: 16:9（1280x720）、マージン0、センタリング無効（`center: false`）。
2. **固定ヘッダー**: 上部100pxに統一されたヘッダーバー（青い下線付き）を配置。スライドが切り替わっても位置が1pxも動かないこと。
3. **タイポグラフィ**:
   - スライド大見出し: 34px〜36px (Bold)
   - 小見出し: 22px〜24px (Bold, 左に青い四角 ■)
   - 本文テキスト: 20px〜22px (Line-height 1.7〜1.8)
   - テーブル文字: 18px〜19px
4. **画像・素材のルール**:
   - AI自作のチープな図は使用厳禁。
   - 企業の公式サイトから取得した公式図・実写写真、または「いらすとや」の標準的なイラストを採用する。
   - 画像エリアの高さ（例: 440px）を全スライドで厳格に固定し、枠の位置ズレを防ぐ。
