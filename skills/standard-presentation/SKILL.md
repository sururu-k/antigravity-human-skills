# Standard Presentation Skill (普通のスライド作成スキル)

このスキルは、学会・インターン報告・大学ゼミ・社内発表などのプレゼンにおいて、**「普通の人間がPowerPointやKeynoteで綺麗に作るような、正統派で誰からも見やすいスライド」**を高速に生成するための手順とツール群です。

AI特有の「安っぽいカードUI」「小さすぎる文字」「スライドごとの枠ズレ」「謎のAI生成図」を根絶し、初手から完成度の高いスライドを作成します。

---

## 📐 基本設計仕様（標準ルール）

| 項目 | 仕様基準 | 理由 |
| :--- | :--- | :--- |
| **画面比率・解像度** | **16:9 (1280 × 720)** 固定 | プロジェクターおよびオンライン発表（Teams/Zoom/Meet）に最適化。 |
| **ヘッダー** | 高さ **100px 固定**（青い下線バー付き） | スライドをめくってもタイトル位置が1pxも動かない。 |
| **メインコンテンツ** | 高さ **440px 固定** | 枠の上下ガタつきや位置ズレを防止。 |
| **フォントサイズ** | 大見出し **34px**, 本文 **21〜22px** | 会場の後方や共有画面でもハッキリ読める大文字設計。 |
| **レイアウト** | **左右2分割**（左: テキスト / 右: 写真・図） | 視線誘導が自然で、説明と視覚資料が1対1で対応する。 |
| **画像仕様** | **Base64インライン埋め込み** | 外部画像切れを防ぎ、HTML単体でオフライン動作可能。 |
| **デザイン原則** | **カードUI・余計な枠線の撤廃** | SaaS風の角丸枠やキャプション帯を排除し、自然なスライドに。 |

## 🛠️ スライド生成スクリプトの使い方

本スキルには、Markdown / JSONから即座にReveal.js HTMLとPowerPointを両方生成するジェネレータが付属しています。

```bash
# スライド設定JSONからHTMLとPPTXを一括生成
python3 scripts/generate_slide.py --config examples/internship_sample.json --output-dir ./dist
```

### スライド設定の書き方 (`slides.json`)
```json
{
  "title": "インターンシップ参加報告",
  "theme_color": "#0072ba",
  "slides": [
    {
      "type": "cover",
      "title": "東海ソフト株式会社\n1Dayインターン参加報告",
      "author": "206 33 村上 大岳",
      "image": "summary_01.jpg"
    },
    {
      "type": "split",
      "title": "企業概要：東海ソフト株式会社",
      "meta": "会社概要",
      "items": [
        { "heading": "商号", "text": "東海ソフト株式会社" },
        { "heading": "事業内容", "text": "独立系SIer" }
      ],
      "image": "access_02.jpg",
      "caption": "本社ビル（名古屋市中村区則武）"
    }
  ]
}
```

## 🎯 エージェントへの行動指示

1. **推測ではなく事実を使うこと**:
   - ユーザーが話した内容・公式Webから取得した一次情報のみをスライドに載せる。
2. **文字を小さくしないこと**:
   - 1枚に情報を詰め込みすぎず、1スライドあたりメッセージは2〜3点に絞る。
3. **実写または公式図を使うこと**:
   - AI自作のチープな図は避け、企業の公式実写・公式図、または「いらすとや」の標準的イラストを配置する。
