# Fact-First Workflow Skill

## 概要
「aiの推測ベースの知識なんて誰も欲しくねぇ」という教訓に基づき、すべてのコード変更・ドキュメント作成・発表内容の策定において、事実検証（Fact-Checking）を最優先する。

## ワークフロー
1. **要求の直接確認**: ユーザーの過去ログ・指示文から「変えてはならない厳格な事実」を抽出する。
2. **一次情報の取得**:
   - Web情報: `read_url_content` や `search_web` ではなく、公式サイトのHTMLを直接curlやスクリプトで解析し、実在する画像・URL・文言を特定する。
   - コード・設定: 実際のソースコード・gitログを読んで確認する。
3. **勝手な追加・脚色の遮断**:
   - ユーザーが指定していない固有名詞、役割、手順を勝手に追加しない。
